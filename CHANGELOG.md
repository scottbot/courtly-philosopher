# Changes

Each version of the edition is listed here, newest first, with what changed and any change to an
address that readers may have cited (see `docs/ANCHORS.md`).

## 0.2 (October 2026)

An AI-produced draft, not reviewed by a specialist. Made by Claude (Anthropic).

Changes from the previous draft:

- **Without JavaScript.** Plain versions of every page, which need no scripts, are generated by
  `tools/build_data.py` into `plain/` (`index`, `book`, `squares`, `about`, `play`; the last explains
  how to play at a table with real dice). Each page links to its plain version from a notice that
  appears only when scripts do not run.
- **Security.** Every page carries a Content-Security-Policy: scripts load only from the site
  itself, and the light/dark snippet moved to `js/theme.js`. A saved game is checked before it is
  shown again, and the build refuses content that could put script into a page.
- **Privacy.** What the site remembers (choices, players' names, a game in progress) is kept under
  the site's own prefix in this browser's storage; the Play setup screen can forget the saved names
  and games, and says what is kept.
- **Printing.** Printouts keep the draft notice and the credits, and print legibly from dark mode.
- **Robustness.** A message when part of a page fails to load; the page for a missing address finds
  the site's root on a GitHub project site; fallbacks for some newer browser features.
- **Fonts.** Font subsets for the Greek letters and combining marks used in the edition.
- **Images.** The figure crops that no longer matched their recorded geometry were rebuilt from the
  masters; `tools/check.sh` rebuilds into a scratch copy and fails if any committed generated file
  differs.
- **Quotations.** `tools/verify_quotes.py` falls back to the text layer of the source PDFs, and to
  a list of quotations verified on page images, where the corpus conversion of a page is defective.
- **Rights and identity.** The British Museum license for the board photograph is recorded
  (README, `LICENSE`, credits on About), with the Google Books usage guidelines for the page images.
  The edition has a version number, this file, `CITATION.cff` and guidance on how to cite it. The
  two master files are identified by size and SHA-256 (README, "Masters").
- **Documentation.** `docs/FORMATS.md` (the formats of the source files), `docs/ANCHORS.md` (which
  addresses are kept from version to version), `docs/REVIEW_CHECKLIST.md` (releasing a version, and
  the change from draft to reviewed).
- **Content.** Translators' working notes were moved out of `content/C_part1.md` and
  `content/C_part2.md` into the research notes; paths in maintainers' comments are relative; links
  to four external sites (giochidelloca.it, fleurtyherald.wordpress.com, ojs.uv.es, eprints.ucm.es)
  now use `https://`.
- **Repository.** `.gitignore` and `.gitattributes` (line endings are stored as the tools write
  them).

- **Pages and leaves of the book.** The Book can be linked by page of the 1588 book (`text.html#p32`)
  and by leaf (`text.html#leaf-B4v`), as well as by segment and by page of the scan; each passage
  shows its page and leaf.
- **Corrections.** Square 1: the numeral 1 is engraved above the peacock's crest (the edition had
  said none could be seen).

No existing anchor changed in this version; `#pN` and `#leaf-…` are new.
